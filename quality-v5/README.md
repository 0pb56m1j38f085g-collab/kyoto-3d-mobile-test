# 清水寺・造形品質プレビュー v5

旧公開版を壊さずに、本堂の大きな輪郭、左右の翼廊、屋根のない張り出した舞台、軒下の格子、植栽と照明を一体で検証する別ブランチです。コンセプト画像の貼り付けや再生成ではなく、すべての建物・木・地形を実際の3D形状で描画します。

## 建築の参照元（一次資料）
- 文化庁・文化遺産オンライン「清水寺本堂」: https://online.bunka.go.jp/db/heritages/detail/145428
  桁行九間・梁間七間、寄棟造、正面両翼廊と庇、西面翼廊、檜皮葺、正面舞台という構成を照合。
- 音羽山清水寺公式「歴史」: https://www.kiyomizudera.or.jp/history.php
  崖上の懸造り、舞台の18本の主要柱、縦横に通る貫の構造を照合。
- 音羽山清水寺公式「境内案内」: https://www.kiyomizudera.or.jp/map.php
  本堂周辺の建物識別用。八坂の塔や装飾的な滝を本堂直近の実景として扱わない。

**寸法・柱位置・彫刻・樹木の分布・参道・地形は、資料を参考にした造形上の解釈です。実測図や保存修理図からの精密な復元ではなく、実際の経路案内には使えません。** 18本や九間七間という仕様が一致することは、実景全体が正確であることの証明ではありません。春の配色は造形比較のため固定しています。

## 描画方式
ネイティブWebGL2、インスタンシング、実形状への事前計算照明。多重反射光と面光源の影を、モデルを回転しても表面に正しく残る頂点データとして保存します。静止画を背景に貼って動かす方式ではありません。計算済みの照明は固定した日照条件であり、リアルタイムの天候・太陽の移動には対応していません。

## 再現可能なビルド
```sh
node quality-v5/build.cjs --validate-only
node quality-v5/build.cjs
```
Node.js と g++ / OpenMP が必要です。外部パッケージ、APIキー、クラウドGPUは使いません。ビルド中の照明計算はCPU性能により時間がかかります。

`base/` は既存リポジトリの固定された基礎ファイル。`patches.json` をチェックサム照合のうえ適用し、`site/` に実行ファイルを生成します。`scene.js` を実行して検証した形状と、照明に使う形状が同一であることをSHA256で確認し、別のモデルに古い照明を誤適用しないよう停止条件を設けています。公開するのは `quality-v5/site` だけです。

公開先では旧本番サイトと分離してください。自動生成した `build-info.json` でモデルの版、ハッシュ、照明サイズを確認できます。

## プライバシー・操作
GPS、位置情報取得、アクセス解析、広告SDKは含めていません。診断情報は端末内で集計し、コピー操作をしない限り送信しません。ホスティング側の通常のアクセスログは別です。1本指で回転、2本指で拡大・移動。止まっている間は描画を止め、画質設定でモデルの形状は削りません。

## 検証の区別
JavaScript構文・有限な頂点と寸法・照明とモデルの対応はビルド時に検証します。ブラウザ上での描画テストと、実機iPhone/Androidの性能検証は区別します。スクリーンショットが美しくても実機性能を確認したとは扱いません。
