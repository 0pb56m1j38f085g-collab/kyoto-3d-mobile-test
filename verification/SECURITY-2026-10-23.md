# Render security update — 2026-10-23

Status: implementation prepared; patched-runtime build, browser validation and publication pending.

Scope: the current Higashiyama/Gion static site, Render service `srv-dbcf79mktt5c73f8l7cg`. Older test services and unrelated applications are not included.

The previous live deploy `dep-dbdjkjlg1s2s73bnurv0` used Node.js 24.21.0. The build uses Node.js fetch for HTTPS downloads, so Render's eMudhra/Node.js advisory applies even though the resulting app is static. PHP is not used in this build or published site.

Changes:

- Pin Node.js 24.22.1 in the repository and use that same file for CI build/browser jobs.
- Reject a mismatched build runtime before any HTTPS download, including a conflicting hosting override.
- Record Node.js/OpenSSL versions in the build log and build-info.json.
- Rebuild and redeploy to receive Render's updated system certificate store.
- Preserve all v4.26 scene, street, material, lighting and interaction source files.

References checked:

- https://render.com/docs/advisory-emudhra
- https://render.com/docs/node-version
- https://render.com/docs/advisory-php2shell

Verification and final deployment evidence will be recorded here after completion. Prior v4.26 browser results are a visual baseline, not a substitute for verification of this update.
