# 清水寺ミニチュア / スマートフォンテスト 01

本堂モデルv4と近くの庭だけを表示する、実機確認用のWebGL 2ページです。
本堂の形状・法線・UV・配置・色・材質識別値を元版とハッシュ照合して保持しています。

## 操作

1本指の回転、2本指のピンチ・移動、視点リセット、3つの視点、説明シート、画質切替。
描画は操作・表示変更時だけです。画質切替で本堂の形状は減らしません。
低速時に標準モードの描画解像度を一度だけ下げる処理を含みます。

## 公開状態

未公開です。Vercelの接続待ちで、実際のURLはまだ発行されていません。
ローカルHTMLファイルや添付リンクは、一般公開URLではありません。
公開用フォルダーの index.html と src/ をそのまま配信します。
vercel.json は静的配信、noindex、位置情報・カメラ・マイクの禁止、CSPを設定します。
noindex はアクセス制限ではありません。公開時の認証状態は別途確認が必要です。

## 描画品質と対象範囲

実際の3Dです。前回のオフライン描画に含まれた多重反射は、このリアルタイム表示にはありません。
リアルタイムとオフラインの画質が一致したという成果物ではありません。
本堂と近くの庭だけが表示範囲です。正確な地理モデルや交通案内はまだ含みません。
春固定の比較用見本であり、将来のアプリの季節自動変更とは区別します。

## プライバシー

位置情報・解析SDK・利用者認証・サーバー保存・外部ライブラリは実装していません。
診断情報はメモリ内だけで集計し、コピー操作時にユーザーへ表示します。自動送信しません。
配信事業者が保持する通常のアクセスログまでゼロであるという意味ではありません。

## 検証

Chromium + ANGLE/Mesaのソフトウェア描画で32項目を検証。
390x844を中心に、412x915、360x740、844x390のCSS画面サイズと疑似タッチを使用。
iPhone Safari / Android実機のフレームレート・発熱・GPUメモリは未確認です。
最初のまとめたテストは180秒の実行枠を超えたため、残りを別プロセスで実施しました。
HTMLのローカル読み込みによる検証で、公開先のHTTPヘッダーやURL到達性のテストではありません。

kiyomizu-crafted-v4-source.zip のモデル生成コード・描画コード。
本堂の形状はそのままで、表示範囲の選択・画面・モバイル操作・描画設定を変更しました。
